# LMS Frontend

A modern and responsive Learning Management System frontend built with Vue 3 and Vite. The application provides an intuitive learning experience for students and instructors while integrating seamlessly with the LMS Backend API.

## Features

- User Authentication
- Student Dashboard
- Instructor Dashboard
- Course Catalog
- Course Enrollment
- Lesson Viewer
- Quiz & Assessment Interface
- Progress Tracking
- Certificate Viewing
- Responsive Design

## Tech Stack

- Vue 3
- Vite
- Vue Router
- Pinia
- Axios
- Bootstrap 5
- JavaScript
- HTML5
- CSS3

### Students

- Register & Login
- Browse Courses
- Enroll in Courses
- Complete Lessons
- Take Assessments
- View Results

### Administrators

- User Management
